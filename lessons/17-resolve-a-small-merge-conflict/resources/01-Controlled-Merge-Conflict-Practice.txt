Resolve expense_tracker/practice_conflict.py to contain:

def format_total(amount: str) -> str:

Stage and review the resolution:

Add a second test to tests/test_practice_conflict.py for the combined requirement:

def test_format_total_combines_label_and_currency():
    assert format_total("12.50") == "Overall total: USD 12.50"

git add expense_tracker/practice_conflict.py tests/test_practice_conflict.py
git status --short
git diff --cached -- expense_tracker/practice_conflict.py tests/test_practice_conflict.py

Run the affected test before completing the merge:

python -m pytest tests/test_practice_conflict.py -q

After the test passes and the staged diff matches the intended behavior, complete the merge:

git commit -m "Merge label and currency formatting"
git status --short
