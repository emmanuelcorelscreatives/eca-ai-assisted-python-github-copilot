# Expense tracker reference starter

From this folder, run the application:

    python -m expense_tracker

Run the initial smoke test:

    python -m pytest tests/test_smoke.py

If pytest is missing from the intended project environment, install the development dependencies into that environment:

    python -m pip install -r requirements-dev.txt
