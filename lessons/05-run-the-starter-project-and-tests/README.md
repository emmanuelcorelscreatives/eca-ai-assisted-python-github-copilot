# 5. Run the Starter Project and Tests

Emmanuel Corels Academy

Run the supplied application skeleton and initial pytest smoke test, and diagnose an incorrect interpreter or missing dependency.

[Course repository](https://github.com/emmanuelcorelscreatives/eca-ai-assisted-python-github-copilot)

- [Reference starter files](resources/01-Reference-starter-files.txt)

Create a new empty folder outside this checkout, for example `python-starter`,
and open it in VS Code. Create the resource's named files and directories there,
copying only each file's contents, not the `--- filename ---` separators. Select
your course Python environment, then run its application and smoke-test commands
from that new folder. Expected: `Expense tracker starter ready` and one passing
smoke test. Do not replace the existing checkout's application or tests; use
[the root practice guide](../../practice/README.md) to run those instead.
