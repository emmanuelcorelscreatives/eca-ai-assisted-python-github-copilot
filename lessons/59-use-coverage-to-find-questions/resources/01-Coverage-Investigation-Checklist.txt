COVERAGE INVESTIGATION

Run from the checkout root with the course environment selected. Provision the
lesson-local plugin first: python -m pip install pytest-cov
Record this development dependency using your own project's version policy.
The supplied root requirements install pytest only; --cov needs this plugin.

Run the suite with line and branch information:
python -m pytest --cov=expense_tracker --cov-branch --cov-report=term-missing

For one uncovered route, answer:
[ ] Which file and line does the report identify?
[ ] What condition leads to the uncovered route?
[ ] Which supported input can reach it?
[ ] What written requirement defines the expected behavior?
[ ] What observable result should a test assert?
[ ] What realistic defect would make that test fail?
[ ] Is this the appropriate test boundary for the behavior?

Example requirement:
The root practice parse_amount rejects nonnumeric text with ValueError and
the message: amount must be a positive finite decimal.
Inspect your own report before deciding this exception branch needs a test.

Example test:
import pytest

from expense_tracker.domain import parse_amount


def test_parse_amount_rejects_non_numeric_text():
    with pytest.raises(ValueError, match="positive finite decimal"):
        parse_amount("not-a-number")

If not already present, add this focused case to tests/test_domain.py in your
practice copy; do not replace that file or duplicate a test already supplied.

Run the focused case:
python -m pytest tests/test_domain.py::test_parse_amount_rejects_non_numeric_text

Rerun the complete measurement:
python -m pytest --cov=expense_tracker --cov-branch --cov-report=term-missing

Decision rule:
Add the test when it checks required behavior and can detect a meaningful defect. Do not add a test whose only claim is that an uncovered line executed. Coverage points to places to investigate; it does not certify correctness.
